# MotoCare

Website Vehicle Maintenance Tracker untuk kelompok 15.

## Fitur tampilan
- Dashboard kondisi kendaraan
- Riwayat perawatan dan biaya servis
- Pengingat servis berdasarkan tanggal dan estimasi kilometer
- Tampilan responsif desktop dan mobile
- Struktur HTML semantic dengan CSS terpisah

Buka `index.html` di browser untuk melihat project.
