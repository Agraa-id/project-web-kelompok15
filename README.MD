# MotoCare

Website Vehicle Maintenance Tracker untuk kelompok 15.

## Fitur tampilan
- Dashboard kondisi kendaraan
- Riwayat perawatan dan biaya servis
- Pengingat servis berdasarkan tanggal dan estimasi kilometer
- Daftar merek motor dari REST API NHTSA dengan status loading, error, dan coba lagi
- Tampilan responsif desktop dan mobile
- Struktur HTML semantic dengan CSS terpisah

Buka `index.html` di browser dengan koneksi internet untuk melihat project dan memuat data API NHTSA. Jika browser membatasi permintaan API saat membuka file lokal, jalankan project melalui server lokal.
